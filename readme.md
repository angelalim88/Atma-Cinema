# 🎥 Atma Cinema

Atma Cinema is a cinema app that allows users to view movie schedules, book tickets, view movie details, rate movies, and more. This app uses Flutter for the frontend and Laravel for the backend.

## Features
- **Now Playing Movies**: Users can view a list of movies currently playing in theaters.
- **Coming Soon**: Users can see upcoming movies that will be released soon.
- **Movie Details**: Displays detailed information about each movie, including genre, duration, and synopsis.
- **Ticket Booking**: Users can select seats and proceed with ticket payment.
